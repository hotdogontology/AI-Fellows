# AI Fellows

Projects, classroom tools, and data work from the GSSM AI Fellows, organized by year. Some projects were created with help from AI tools, including Codex.

## Repository layout

- [AI Fellows 2026](AI-Fellows-2026/): projects and resources from the 2026 cohort.
- [AI Fellows 2027](AI-Fellows-2027/): projects and resources for the 2027 cohort.

Each year contains folders for individual fellows, shared examples, or standalone projects. Both years are part of this repository.

## Getting started

Clone the repository:

```bash
git clone https://github.com/hotdogontology/AI-Fellows.git
cd AI-Fellows
```

This repository is private, so cloning requires a GitHub account with access.

Open the folder for the year and project you want to work on. Follow that project's README for setup and usage. Requirements vary by project; there is no single installation or build command for the whole repository.

## Adding or updating a project

1. Put your work under the appropriate year, in a folder named for you or your project.
2. Include a short README explaining what it does, how to run it, and any dependencies.
3. Keep related code, resources, and documentation together. For datasets, document the source, units, and preparation steps.
4. Review your changes before committing. Keep credentials, personal student information, and data without sharing permission out of Git.

Run Git commands from the repository root or a project folder. New projects belong in this shared repository; they do not need a separate `.git` folder.
